# Contribution

Lire `docs/16_cadre_de_livraison.md` avant de commencer un lot.

1. Creer une branche courte depuis `main`.
2. Ecrire ou adapter les tests avant la regle/metier sensible.
3. Executer lint, formatage et tests.
4. Ouvrir une PR petite avec le modele fourni.
5. Ne jamais commiter de `.dem`, de fichier de donnees local, de token ou de SteamID brut.

Les changements de parsing, persistance, authentification, secret ou politique securite exigent une revue renforcee.
